# 补齐 8 项前端缺口 + i18n 完整接线

## 目标

PRD-v2 §5 标 `[P0]` 但前端未实现的 8 项能力全部补齐，加上 i18n 半成品完成。

## 实现清单（按文件分组）

### 1. Lite 模式（2D 降级）— §6.12 `[P0]`
- **新建 `components/room/LiteGrid.tsx`**：用 CSS grid 平铺 `AvatarImage`（圆头像），说话者加 `ring-rose` 高亮 + 脉冲动画；替代 3D `PartyScene`
- **修改 `components/RoomView.tsx`**：加 `useLiteMode()` hook 判断条件（`prefers-reduced-motion: reduce` OR `navigator.hardwareConcurrency <= 4` OR 弱网 `navigator.connection.effectiveType in ['2g','slow-2g']`），条件渲染 `<LiteGrid>` vs `<PartyScene>`
- **修改 `lib/store.ts`**：加 `liteMode: boolean` 状态

### 2. 分层捏脸 UI — §6.1 `[P0]`
- **修改 `lib/avatar.ts`**：`avatarDataUri` 接受可选 `options` 参数（`backgroundColor`, `radius` 等），透传给 DiceBear；定义 `AVATAR_CONFIG_SCHEMA`（layer → options 映射）
- **修改 `components/AvatarPicker.tsx`**：DiceBear 模式下新增"捏脸"展开区——底色选择（6 色块）、背景色选择（6 色块）、圆角滑块；选择写入 `avatar_config jsonb` 结构 `{ bgColor, radius, backgroundColor }`
- **修改 `app/onboarding/page.tsx`**：保存时带上 `avatar_config`
- **修改 `lib/avatar.ts:resolveAvatarSrc`**：接受 `avatarConfig` 参数，应用到 DiceBear options

### 3. OAuth 登录按钮 — §6.1 `[P0]`
- **修改 `app/login/page.tsx`**：在邮箱 OTP 表单下方加分隔线 + 三个 OAuth 按钮（Google / Apple / Discord），调用 `supabase.auth.signInWithOAuth({ provider, redirectTo })`；按钮样式匹配 `btn-rose` 风格（白底 + provider 图标）
- OAuth provider 是否实际可用取决于 Supabase Dashboard 配置；前端按钮无条件渲染（未配时报 Supabase 返回的错误）

### 4. 兴趣标签选择器 — §6.1 `[P0]`
- **修改 `app/onboarding/page.tsx`**：AvatarPicker + 昵称之后加兴趣选择步骤——预置分类（音乐/游戏/情感/学习/二次元/影视/运动/职场/读书/K歌），可选 3-10 个，选中高亮；保存时写入 `interests text[]`
- **新建 `components/InterestPicker.tsx`**：可复用的多选标签组件，props `{ selected: string[], onChange, min, max }`

### 5. 录制开关 UI — §6.7 `[P0]`
- **修改 `lib/room-roles.ts`**：`ModerateAction` union 加 `'toggle_recording'`
- **修改 `lib/livekit-server.ts`**：加 `egressClient` (EgressClient) 导出
- **修改 `app/api/livekit/moderate/route.ts`**：加 `toggle_recording` case——查当前 `recording_enabled`，取反；开 → 调 `egressClient.startRoomCompositeEgress`；关 → 查活动 egress id → `egressClient.stopEgress`；更新 `rooms.recording_enabled`
- **修改 `components/HostPanel.tsx`**：host 专用区块加录制开关按钮（开/关切换），调用 `/api/livekit/moderate { action: 'toggle_recording' }`

### 6. 建房时选主题/可见性 — §6.2 `[P0]`
- **修改 `components/CreateRoomButton.tsx`**：建房表单加 topic 下拉（闲聊/树洞/学习/K歌/游戏/读书/情感/职场/其它）+ visibility 选择（公开/关注者/私密）；私密房自动生成 invite_code
- **修改 `app/api/rooms/route.ts`**：接受 `inviteCode`，私密房时生成并存储

### 7. Web Push 客户端注册 — §6.12 `[P0]`
- **新建 `lib/push.ts`**：`registerPush()` 函数——检查 `'serviceWorker' in navigator && 'PushManager' in window`，请求 Notification 权限，调 `pushManager.subscribe({ userVisibleOnly, applicationServerKey })`，POST 到 `/api/push/subscribe`
- **修改 `app/settings/page.tsx`**：通知设置区块加"开启推送通知"按钮 + 权限状态显示

### 8. 在线状态 + Ping 拉人 — §6.6 `[P0]`
- **新建 `components/room/PresenceList.tsx`**：用 LiveKit `useParticipants()` 显示"在场成员"列表（头像 + 名字 + 角色 badge），每个关注对象旁边显示"邀请"指示
- **修改 `components/RoomView.tsx`**：在 HostPanel 旁边或房间信息栏集成 PresenceList
- **Ping 实现**：简化为"分享房间链接"——因为跨房间 Ping 需要通知后端复杂度较大，P0 用"复制邀请链接"按钮替代

### 9. i18n 完整接线（半成品完成）
- **修改 `package.json`**：加 `next-intl` 依赖
- **新建 `i18n/request.ts`**：next-intl 服务端配置
- **修改 `app/layout.tsx`**：包 `NextIntlClientProvider`
- **修改所有硬编码组件**：用 `useTranslations()` / `getTranslations()` 替换硬编码中文字符串，共约 14 处（ChatPanel、RoomView、MicControls、HostPanel、CreateRoomButton、onboarding、login、ConsentGate 等）
- **修改 `middleware.ts`**：加 `locale` 检测/路由
